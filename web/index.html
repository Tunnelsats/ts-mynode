            Verify Routing on the Node

            MyNode Host CLI

            WireGuard (wg-quick@tunnelsatsv2.service), tunnelsats.slice, and the fail-closed tunnelsats-killswitch.service (inet tunnelsats) run natively on the MyNode host kernel via tunnelsats.sh --managed mynode --impl lnd. To inspect the live tunnel and routing rules, attach to your MyNode device over SSH:

            Attach to MyNode host
            ssh admin@mynode.local
            • sudo /usr/local/sbin/tunnelsats verify --json Managed dataplane and kill-switch attestation
            • sudo wg show tunnelsatsv2 WireGuard interface and peer handshake
            • ip rule Policy routing rules (priority 21821 to table 51820)
            • ip route show table 51820 Tunnel routing table (default dev tunnelsatsv2)
            • sudo systemd-run -q -P --slice=tunnelsats.slice curl -4s https://ifconfig.me IPv4 egress inside tunnelsats.slice (returns TunnelSats VPN IP)
            • sudo systemd-run -q -P --slice=tunnelsats.slice curl -6s https://ifconfig.me IPv6 leak test inside tunnelsats.slice (blocked by kill switch)
            How MyNode Protects Your Node (tunnelsats-killswitch.service)
            Fail-Closed Kernel Guard
            1. LND-Only Split Tunnel

            Frequently Asked Questions

            How does TunnelSats work on MyNode?

            TunnelSats manages your subscription, generates your X25519 WireGuard keys locally on MyNode (/mnt/hdd/mynode/tunnelsats/tunnelsatsv2.conf), configures hybrid Clearnet + Tor routing in /mnt/hdd/mynode/settings/lnd_extra_config.conf, and isolates LND (lnd.service) inside the fail-closed tunnelsats.slice kernel dataplane (tunnelsats.sh --managed mynode --impl lnd).

            How do I back up or export my WireGuard configuration before uninstalling or reflashing MyNode?

            Unlike appliance-wide backup images, uninstalling an app or reflashing your MyNode drive can remove local app data if not backed up first. Always click the Backup .conf pill in the top header to download tunnelsatsv2.conf to your computer before uninstalling.

            Your tunnelsatsv2.conf file contains your WireGuard private key and dedicated port; you can restore your active subscription anytime on a fresh MyNode installation via Import Subscription.

            How do I buy, renew or import a subscription?

            Use the interactive Server Region and Duration pills directly on this dashboard, or open the Actions & Plans tab in this dashboard:

            • Buy Subscription creates a WireGuard key on this server, fetches a BOLT11 Lightning invoice, and displays a scannable QR code.
            • Renew Subscription extends the current WireGuard key in place.
            • Import Subscription installs a .conf file bought on tunnelsats.com.
            Does MyNode support automatic subscription renewal?

            Yes, via Nostr Wallet Connect (NWC). Open the Actions & Plans tab in this dashboard, click Connect Wallet, and paste a nostr+walletconnect:// URI (Alby Hub, LNBits, Cashu/Minibits, or self-hosted NWC). When your subscription is within 7 days of expiry, TunnelSats requests a renewal invoice and pays it automatically (with optional Tor SOCKS5 routing).

            If the wallet balance or budget is too low, or NWC fails 3 times, TunnelSats displays the renewal invoice on this dashboard so you can pay manually. MyNode does not have an OS push notification inbox; without NWC, this dashboard highlights your subscription in amber at 7 days (Renew soon) and red at 3 days (Renew now) before expiry.

            How do I switch between Mode A (Integrated) and Mode B (Secure CLI)?

            Open the Actions & Plans tab in this dashboard and use the MyNode Execution Mode & Host Reconciler card to switch between Mode A (1-click sudoers reconciler) and Mode B (Manual SSH CLI mode).

            What happens if the VPN drops or my subscription expires?

            When a subscription expires, the TunnelSats server disables the WireGuard peer and clearnet peer traffic stops working through TunnelSats. Renew the subscription or click Restore Tor-Only Mode.

            The independent tunnelsats-killswitch.service (inet tunnelsats nftables table) remains armed even if wg-quick@tunnelsatsv2.service stops, preventing clearnet IP leaks from tunnelsats.slice.

            How are WireGuard keys and configurations protected on MyNode?

            WireGuard private keys are generated locally on your MyNode device and stored with 0600 permissions in /mnt/hdd/mynode/tunnelsats/tunnelsatsv2.conf. Import and export endpoints require same-origin CSRF tokens over POST and are never exposed on read-only GET endpoints.
